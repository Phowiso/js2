# Проект «Страны-Города» на Next.js

Учебный проект — страны и их города.

## Задание

1. Файл с многомерной структурой данных (страны + города)
2. Главная — список стран (ссылки)
3. Страница страны — описание + список городов
4. Страница города — описание + ссылка на страну

## Запуск

```bash
npm install
npm run dev
```

Открыть: http://localhost:3000

## Технологии

- Next.js (App Router)
- TypeScript
- CSS Modules
