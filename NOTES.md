# Заметки по проекту «Страны-Города в Next.js»

## Что сделано

Выполнены все 4 пункта задания:

1. Файл с многомерной структурой данных (страны + города)
2. Главная страница — список всех стран (ссылки)
3. Страница страны — описание + список городов (ссылки)
4. Страница города — описание + ссылка на страну

---

## Подробное описание действий

### 1. Файл с данными (задание №1)

**Файл:** `src/data/countries.ts`

**Структура:**
```ts
interface City {
  id: string;
  name: string;
  area: number;        // площадь
  population: number;  // население
  founded: number;     // год основания
}

interface Country {
  id: string;
  name: string;
  language: string;    // язык
  area: number;
  population: number;
  cities: City[];      // массив городов
}
```

Это **многомерная структура**: массив стран, у каждой страны — массив городов.

**Функции-хелперы:**
- `getAllCountries()` — все страны
- `getCountryById(id)` — найти страну
- `getCityById(cityId)` — найти город + его страну (нужно для ссылки назад)

**Данные:** 5 стран (Россия, Германия, Япония, Франция, Бразилия), у каждой по 3 города.

---

### 2. Главная страница (задание №2)

**Файл:** `src/app/page.tsx`

- Получаю все страны через `getAllCountries()`
- Вывожу список `<Link href={`/country/${country.id}`}>`
- Показываю название + язык + количество городов

---

### 3. Страница страны (задание №3)

**Файл:** `src/app/country/[id]/page.tsx`

- Динамический роут `[id]`
- `generateStaticParams()` — статические страницы для всех стран
- Описание: язык, площадь, население
- Список городов как ссылки на `/city/[cityId]`

---

### 4. Страница города (задание №4)

**Файл:** `src/app/city/[id]/page.tsx`

- Динамический роут `[id]`
- `generateStaticParams()` — генерирую параметры для всех городов всех стран
- Описание: площадь, население, год основания
- Ссылка на страну: `/country/${country.id}`

## Возможные вопросы преподавателя

**Q: Что такое многомерная структура?**  
A: Массив объектов, где у каждого объекта есть вложенный массив (cities). Страна → города.

**Q: Как связаны страна и город?**  
A: Город хранится внутри массива cities у страны. Функция getCityById ищет город по всем странам и возвращает и город, и страну.

**Q: Почему два динамических роута?**  
A: Один для стран (`/country/[id]`), один для городов (`/city/[id]`). Так проще и понятнее.

**Q: Что делает generateStaticParams?**  
A: Говорит Next.js заранее сгенерировать HTML-страницы для всех id при сборке (SSG).
